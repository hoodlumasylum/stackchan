Operation mode

Choose what Stack-chan mainly does. "Conversation" talks with you using an AI service (Grok / OpenAI / Gemini / XiaoZhi), "Random talk" makes it babble idle phrases, "Mic lip-sync" just moves the mouth to the microphone input. Takes effect after Save & Restart.

Device name (BLE / mDNS)

Used for the Bluetooth name and the mDNS host name. Leave blank for automatic (Stackchan-XXXXXX). mDNS keeps only letters, digits and hyphens. Takes effect after restart.

Settings password

When set, this settings page (Wi-Fi) and the Bluetooth settings both ask for this password. Save it blank to turn the password off. Wi-Fi uses HTTP Basic Auth (applies immediately); Bluetooth applies on the next connection.

sanoTTS-jp (neural TTS)

sanoTTS-jp weights (654 KB) switch jtts to neural synthesis (22.05 kHz) (boards with PSRAM). Readings use the same notation as HTS voices (' nucleus, / break). The weights are not bundled with this firmware; the robot downloads them directly from the official GitHub Releases.

Touch

While a reply is playing, tapping the avatar screen (head) interrupts the AI reply. The touch sensor is sensitive and easily triggered, so this is off by default. Petting (front→middle→back swipe) always works regardless. Applies immediately (no restart).

Firmware update (OTA)

Choose a local firmware.bin and press "Write" to write the new firmware to the other partition and restart. Much faster over Wi-Fi than Bluetooth.

How to write the latest release from a local file (works on iPhone / in hotspot mode)
  1. In Safari, open ciniml.github.io/stackchan-idf .
    (In hotspot mode, if the Wi-Fi has no internet, iOS falls back to cellular automatically. If it does not connect, turn Wi-Fi off once and try again.)
  2. Download the firmware-vX.Y.Z-<board>.zip for your board
  3. In the Files app, tap the ZIP to extract it → the stackchan_idf.bin inside is the OTA payload
  4. (In hotspot mode) Join the device's hotspot and open this page again
  5. Use "Choose file" above to pick stackchan_idf.bin and press "Write"

※ firmware-vX.Y.Z-<board>.bin — not stackchan_idf.bin . The latter is a combined bootloader + partition + app image (for first-time USB flashing) and cannot be used for OTA.

⚠ If "Choose file" does nothing on Android:

  1. If this page opened in the "Sign in to network" mini browser (CaptivePortalLogin), file selection does not work.
  2. In the top right ⋮ menu → "Use this network as is" (this keeps the connection to the Stackchan hotspot).
  3. Chrome Open http://192.168.4.1/ , go to the address, and choose the file / run the OTA there.
* Even if Android says "No internet connection", stay connected. If it switches back to your usual Wi-Fi, choose the Stackchan hotspot again in Wi-Fi settings.

Get directly from a release (device side fetch)

The device downloads its own build from GitHub Pages over STA and applies it via OTA. Works in hotspot mode as long as home Wi-Fi is also up (APSTA). If home Wi-Fi is down it fails, so use "Local file" above.

Picking from the dropdown fills the text box on the right. You can also type (future tag / special build). The board (cores3 / atoms3r / atoms3 / stopwatch) is detected on the device. Progress shows in the status bar below.

⚠ Releases cannot be fetched in hotspot mode (no home Wi-Fi). Use "Local file upload" above.
