Device name (BLE / mDNS)

Used for the Bluetooth name and the mDNS host name. Leave blank for automatic (Stackchan-XXXXXX). mDNS keeps only letters, digits and hyphens. Takes effect after restart.

Settings password

When set, both this Bluetooth settings page and the Wi-Fi settings page ask for the password. Bluetooth mixes the password hash into the encryption key, so with a wrong password nothing can be decrypted. HTTP uses Basic Auth. Clear it to turn the password off. Takes effect after restart.

Speaker volume

Applies to every output (internal / Module Audio / Atomic Echo Base). Moving the slider applies immediately and saves automatically (no restart). 100% = board default, 200% = boost (doubles the internal master volume, saturating at 255).

Test Japanese voice (jtts)

Type hiragana / katakana and press "Speak" to hear the Japanese voice (jtts). Kanji and Latin letters are not converted. Handy for checking volume and audio output.

sanoTTS-jp voice model

The robot downloads the weights from the official GitHub Releases (ayutaz/sanoTTS-jp) over its own Wi-Fi and stores them. Please check the model terms (LICENSE-MODEL.md) yourself. If downloaded, sanoTTS is used first. Writing from a file is done on the Wi-Fi settings page.

Play audio file (Bluetooth streaming)

Choose a local audio file (.mp3 / .wav / .m4a / .aac etc.) and press "Play": the browser re-encodes it to 24 kHz mono AAC-LC and streams it over Bluetooth. Stack-chan decodes and plays it, moving its mouth to the volume.

⚠ Not available because Conversation is on. They compete for radio/CPU and playback would stutter. Turn "Enable conversation" OFF and Save & Restart to use it.

Start/stop on the device's "LT" tab. Here you set the default time and announcement words (Write applies immediately; Save keeps them after restart). Readings must be hiragana (jtts cannot read kanji).

AI provider & API keys

Touch

While a reply is playing, tapping the avatar screen (head) interrupts the AI reply. The touch sensor is sensitive and easily triggered, so this is off by default. Petting (front→middle→back swipe) always works regardless. Takes effect after restart.

Device features on/off

Shows a battery gauge at the top left of the avatar screen (after restart)

Whether to play the C5–E5–G5 chime (speaker check) at startup. OFF = silent startup (takes effect after restart)

When off, servo power is not turned on and the servo task does not start (after restart). Different from the relax/restore toggle on the Control screen; this one is saved permanently.

Servo center & range (for custom bases such as Takao base)

Servo mounting direction and range differ by base board. Set the center (0..1023) and range (degrees), then press "Save & Restart". Defaults are for the M5 base.

Turning range mode ON relaxes the servos so you can capture positions by moving the head by hand. Tap "Capture yaw center" at the middle, "Capture yaw min" at the left end and "Capture yaw max" at the right end. Captured values appear in the fields above. Finally press "Save & Restart".

Cat-ear LEDs

Set the mode, color and brightness of the cat-ear NeoPixels (GPIO9 / 18 LEDs). Changes apply instantly and are saved automatically, so they are restored after restart. Color is ignored in gradient (rainbow) mode.

The LEDs react when the avatar's mouth opens (works for conversation playback, jtts speech and mic lip-sync). When OFF, they stay at the set brightness. Takes effect after restart.

Choose how the LEDs react when ON. "Brightness" makes all LEDs brighter as the mouth opens (classic). "Level meter" lights the cat-ear triangle (LED1 = base, LED5 = top) as a 5-step bar graph. Takes effect after restart.

Claude Code Channel (MCP) — token

When set, /mcp/* HTTP API is enabled (Channel adapters can connect). When empty, /mcp/* returns 404. Takes effect after restart

Firmware update (OTA)

Choose a GitHub Release or a local build/stackchan_idf.bin and press "Write": the new firmware is written over encrypted Bluetooth to the other partition and the device restarts. Bluetooth disconnects on success, so reconnect manually.
